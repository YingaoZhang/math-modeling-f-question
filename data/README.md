# 数据说明

本目录保存第一问分析所需的附件索引、表格和可公开提交的数据。完整原始附件位于本地 `data/raw/real_attachments/`，其中两个原始样本因超过 GitHub 单文件 100 MB 限制而被 `.gitignore` 排除：

- `A_data_value/regmix_domain_sample.jsonl.xz`（约 165 MB）
- `A_data_value/slimpajama_quality_signal_sample.jsonl.xz`（约 103 MB）

其余小型 A/B/C 表格和元数据会随仓库提交。运行完整分析时，请将上述两个文件放回对应路径；如果只检查代码、报告和已生成结果，则不需要它们。原始附件清单见 `raw/real_attachments/source_manifest.json` 与 `attachment_size_summary.csv`。
